# 트러블슈팅

## React Native

**Q. Metro 개발 서버가 열려 있는데 `잠시 문제가 생겼어요`라는 메시지가 표시돼요.**

개발 서버에 제대로 연결되지 않은 문제일 수 있어요. `adb` 연결을 끊고 다시 `8081` 포트를 연결하세요.

**Q. PC웹에서 Not Found 오류가 발생해요.**

8081 포트는 샌드박스 내에서 인식하기 위한 포트예요.
PC웹에서 8081 포트는 Not Found 오류가 발생해요.

**Q. 연결 가능한 기기가 없다고 떠요**

React Native View가 나타나는 시점에 개발 서버와 기기가 연결됩니다. 개발 서버가 제대로 빌드되고 있는지 확인해 보세요.

**Q. REPL가 동작하지 않아요**

React Native의 버그로 인해 가끔 REPL이 멈추는 현상이 발생할 수 있어요. 콘솔 탭 옆에 있는 눈 모양 아이콘을 클릭하고 입력 필드에 임의의 코드(`__DEV__`, `1`, `undefined` 등)를 입력하고 평가해 보세요.

**Q. 네트워크 인스펙터가 동작하지 않아요**

React Native 애플리케이션에서 여러 개의 인스턴스가 생성될 수 있는데, 현재 네트워크 인스펙터는 다중 인스턴스를 지원하지 않아요. 해결 방법:

1. 앱을 완전히 종료
2. 개발 서버를 중단하고 네트워크 인스펙터를 닫기
3. 앱을 다시 시작하고 `dev` 스크립트를 실행해 개발 서버를 재실행

**Q. '[Apps In Toss Plugin] 플러그인 옵션이 올바르지 않습니다' 에러가 발생해요.**

`granite.config.ts`의 `icon` 설정을 확인해주세요. 아이콘을 아직 정하지 않았다면 `''`(빈 문자열)로 비워둔 상태로도 테스트할 수 있어요.

```ts
icon: '', // 빈 문자열로 설정
```

**Q. 개발 서버 실행 중 too many open files 에러가 발생해요.**

node_modules 디렉터리를 삭제한 뒤 다시 의존성을 설치해 보세요.

```sh
rm -rf node_modules
npm install
```

## WebView

**Q. `서버에 연결할 수 없습니다` 에러가 발생해요.**

`granite.config.ts` 의 `web.commands`에 `--host`를 추가 후, 서비스를 실행하여 호스트 주소를 확인하세요.

```ts
// granite.config.ts
web: {
  host: 'x.x.x.x', // 서비스가 실행되는 호스트 주소를 입력
  commands: {
    dev: 'vite --host', // --host를 추가
    build: 'tsc -b && vite build',
  },
},
```

샌드박스 앱에서 서비스 실행 전, metro 서버 주소도 호스트 주소로 변경해주세요.
