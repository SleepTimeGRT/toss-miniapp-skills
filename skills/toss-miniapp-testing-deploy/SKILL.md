## 1. 테스트앱 (샌드박스)

> 원본 URL: https://developers-apps-in-toss.toss.im/development/test/sandbox.md

앱인토스는 개발용 토스앱을 별도로 제공하지 않아요. 대신 **전용 샌드박스 앱**을 통해 개발/테스트 환경을 구성해요.

> 실서비스 출시 전, 샌드박스 앱에서 기능 검증을 완료해야 해요. 가이드 위반 시 검수에서 반려될 수 있어요.

### 샌드박스 앱 사용 흐름

1. 최신 버전 설치 (수시 업데이트되므로 오류 시 최신 버전 확인)
2. 콘솔의 토스 비즈니스 계정으로 **개발자 로그인**
3. 워크스페이스의 **앱 선택**
4. 토스앱이 설치된 스마트폰에서 **토스 인증** (푸시 승인)
5. 스킴으로 접속: `intoss://{appName}`

### 빌드번호 및 지원 OS

| 구분        | 빌드번호   |
| ----------- | ---------- |
| Android     | 2026-01-26 |
| iOS         | 2026-01-26 |
| iOS(실기기) | 2025-11-11 |

| 구분    | 최소 버전 |
| ------- | --------- |
| Android | Android 7 |
| iOS     | iOS 16    |

> 샌드박스에서는 ATS 정책 완화로 **http 통신이 허용**되지만, 라이브 환경에서는 **https만 지원**돼요.

### 샌드박스에서 테스트 가능한 기능

| 기능                   | 테스트 가능 여부                 |
| ---------------------- | -------------------------------- |
| 토스 로그인            | 가능                             |
| 게임 로그인            | 가능 (단, mock 데이터 내려감)    |
| 토스 페이              | 가능                             |
| 인앱 결제              | 가능                             |
| 게임 프로필 & 리더보드 | 가능                             |
| 분석 / 공유 리워드 / 인앱 광고 / 가로 버전 게임 / 내비게이션 바 공유하기 | 불가능 |

샌드박스 미지원 기능은 콘솔 '출시하기'의 **QR 코드로 토스앱에서 테스트**해 주세요.

## 4. 토스앱 테스트 (번들 업로드 및 QR 테스트)

> 원본 URL: https://developers-apps-in-toss.toss.im/development/test/toss.md

샌드박스 테스트가 완료되면, **앱 번들(.ait)** 을 업로드하고 **토스앱에서 최종 테스트**를 진행해요.

### 1. 앱 번들 파일 생성

```sh
npm run build   # npm 기준. pnpm/yarn도 동일
```

빌드 완료 시 프로젝트 루트에 `<서비스명>.ait` 파일이 생성돼요.

> **앱 번들 용량 정책:** 압축 해제 기준 **100MB 이하**만 업로드 가능. 대용량 리소스는 **CDN/외부 스토리지**에서 다운로드하도록 구성하고, Lazy Loading을 적용하세요.

### 2. 앱 번들 업로드 및 QR 테스트

**방법 1: 콘솔에서 직접 업로드**

1. 콘솔에 `.ait` 파일 업로드 (경로: 워크스페이스 > 앱 > 좌측 **앱 출시**)
2. '테스트하기' 버튼 클릭 → **QR 코드** 생성
3. QR 스캔 → 토스앱에서 미니앱 실행

QR 테스트 조건: 토스앱 로그인 + 워크스페이스 멤버 + 만 19세 이상

**방법 2: CI/CD 명령어**

```sh
npx ait deploy --api-key {API 키}
# 또는 토큰 등록 후:
npx ait token add
npx ait deploy
```

| 명령어                                      | 용도            |
| ------------------------------------------- | --------------- |
| npx ait token add [워크스페이스명] [API 키] | 토큰 등록       |
| npx ait token remove [워크스페이스명]       | 토큰 삭제       |
| npx ait deploy [워크스페이스명] [API 키]    | 번들 업로드     |

### 3. 출시 전 피처 테스트

`intoss://` 스킴은 정식 출시 후에만 접근 가능해요. 출시 전에는 **테스트 스킴**을 사용하세요.

```
intoss-private://appsintoss?_deploymentId={deploymentId}
intoss-private://appsintoss/path/subpath?_deploymentId={deploymentId}
intoss-private://appsintoss?_deploymentId={deploymentId}&queryParams={URL-encoded JSON}
```

### 문제 해결

- **iOS 흰 화면:** 메모리/리소스 부족 → 리소스 용량 최적화, 메모리 누수 점검
- **통신 오류:** CORS Origin에 `https://<appName>.apps.tossmini.com` (실서비스) 및 `https://<appName>.private-apps.tossmini.com` (QR 테스트) 등록 필요
- **ATS:** 라이브 환경에서는 HTTPS만 허용
- **iOS 서드파티 쿠키:** iOS 13.4+에서 완전 차단 → 토큰 기반 인증 적용

## 7. 미니앱 출시 (배포)

> 원본 URL: https://developers-apps-in-toss.toss.im/development/deploy.md

### 1. 사전 점검

- **검수 가이드 및 체크리스트** 확인 (게임/비게임 모두). 미준수 시 반려됨
- 앱 번들 용량: 압축 해제 기준 **100MB 이하**, 리소스는 빌드와 분리 관리

### 2. 검토 요청

- 테스트 **1회 이상 완료** 후 콘솔에서 '검토 요청하기' 클릭
- 검토 소요: **영업일 기준 최대 3일**
- 한 번에 하나의 버전만 제출 가능
- 수정 필요 시: '요청 취소하기' → 새 번들 업로드 → 재검토 요청
- 반려 시: '반려사유 보기'로 사유 확인 후 수정, 문의는 [채널톡](https://apps-in-toss.channel.io/workflows/787658)

### 3. 출시

번들 승인 후 콘솔에서 '출시하기' 클릭 → **즉시 전체 사용자에게 반영**

> **실제 환경 차이 주의:** CORS 정책, 메모리/리소스, 권한 처리, 로그인/세션, 결제/인증이 테스트 환경과 다를 수 있어요. Origin 허용 목록에 `https://<appName>.apps.tossmini.com`과 `https://<appName>.private-apps.tossmini.com`을 등록하세요.

### 4. 출시 후 관리

#### 새 버전 배포

새 `.ait` 업로드 → 검토 요청 → 승인 → 출시하기. 기존 앱을 대체해요.

#### 이전 버전 롤백

'앱 출시' 메뉴에서 이전 출시 버전 선택 → '출시하기' 클릭. 즉시 반영되므로 버전 선택 시 주의하세요.

#### 긴급 수정 (핫픽스)

심각한 오류 발생 시 [채널톡](https://apps-in-toss.channel.io/workflows/787658)으로 즉시 문의하세요.

#### 출시 후 모니터링

- 주요 오류/크래시 로그, [Sentry 모니터링](/learn-more/sentry-monitoring.md)
- API 응답 지연/실패율
- 사용자 피드백 (내비게이션 바 '신고하기' → 콘솔 '신고 내역'에서 확인)
- 외부 리소스/CDN 로딩 지연

## 8. 앱 내 기능 등록

> 원본 URL: https://developers-apps-in-toss.toss.im/development/test/function.md

콘솔의 **'앱 내 기능'** 은 사용자가 검색 결과나 미니홈에서 **특정 기능으로 바로 진입**할 수 있게 해주는 기능이에요.

> **비게임 앱**은 앱 내 기능을 **최소 1개 이상** 등록해야 해요. 검토 소요: 영업일 1~2일.

### 등록 방법

- **신규 출시 앱:** 앱 출시 메뉴에서 번들 업로드 후 함께 등록 → 앱 출시 검토와 동시 진행
- **이미 출시된 앱:** '앱 출시' > '앱 내 기능' 탭에서 별도 추가/수정 → 앱 내 기능만 검토

### 피처 주소 설정

- 기능 이름은 **'~하기'** 또는 **명사형**으로 작성 (예: '식단 기록하기', '해외 송금하기')
- 서비스의 기능이 드러나게 작성 ('보러가기' 등 모호한 표현은 지양)
- **Webview:** 라우터 경로 매핑 → `intoss://{appName}/search`
- **RN (Bedrock):** 파일 기반 라우팅 `/pages/search.tsx` → `intoss://{appName}/search`

## 9. 정산

정산 상세 가이드는 `references/settlement.md` 참조

핵심 요약:
- **정산 정보 등록:** 콘솔 > 나의 워크스페이스 > 정보 > 정산 정보 (거래 계좌 사본 필요)
- **인앱 광고:** 광고 송출 비용(~30%) + 앱인토스 수수료(15%) 공제 후 정산. 익월 말 지급
- **인앱 결제:** 앱마켓 수수료(15%~30%) + 토스 수수료(5%) 공제 후 정산. 익월 말 지급
- **비즈 월렛:** 프로모션/광고 푸시용 선충전 금액. 미사용분 자동 환급
- **세금계산서:** 광고 수익 부가세는 역발행(팝빌 승인 필요), 토스 수수료 부가세는 토스 직접 발행
