# 비게임 출시 가이드 - 전체 체크리스트

> 공식 문서: https://developers-apps-in-toss.toss.im/checklist/app-nongame.html

## 공통 기능별 (필수)

### 1. 접속 및 앱 내 기능

| # | 항목 | 상세 |
|---|------|------|
| 1 | 미니앱 정상 실행 | 미니앱이 정상 작동하며 모든 서비스 기능 이용 가능 |
| 2 | 앱 내 기능 연결 | 등록된 앱 내 기능에서 해당 화면으로 정상 이동 |
| 3 | 앱 스킴 연결 | 등록된 앱 스킴이 정상 연결 |
| 4 | 뒤로가기 | 앱 스킴 진입 후 뒤로가기 버튼 정상 작동 |

### 2. 내비게이션 바

| # | 항목 | 상세 |
|---|------|------|
| 1 | 비게임 내비게이션 바 사용 | 앱인토스 비게임 내비게이션 바 필수 사용 |
| 2 | 좌측 뒤로가기 | 뒤로가기 버튼 정상 작동 |
| 3 | 중앙 브랜드 표시 | 브랜드 로고와 미니앱 명칭(국문) 표시 |
| 4 | 중앙 홈 버튼 | 홈 버튼 작동 (선택사항) |
| 5 | 우측 기능 버튼 | 최대 1개만 노출 (선택사항) |
| 6 | 중복 뒤로가기 금지 | 토스 네비게이션과 자체 구현 뒤로가기 동시 노출 금지 |
| 7 | 더보기 버튼 | 더보기(⋯)에서 신고, 공유 등 토스 공통 기능 제공 |
| 8 | 닫기/뒤로가기 구분 | 닫기와 뒤로가기 버튼이 명확히 구분됨 |

| 4 | 인터랙션 지연 금지 | 스크롤, 터치, 화면 전환 등 2초 이상 지연 금지 |

| 12 | 권한 미허용 대응 | 권한 미허용 시에도 기능 정상 작동 |
| 13 | 네트워크 사용량 | 비정상적 네트워크 사용량 증가 금지 |
| 14 | 메모리 사용량 | 비정상적 메모리 사용량 증가 금지 |

### 4. UX

| # | 항목 | 상세 |
|---|------|------|
| 1 | 바텀시트 자동 금지 | 진입 시 바텀시트 자동 미개방 |

## 선택 기능별

선택 기능의 QA 항목은 각 기능 스킬에서 관리합니다:
- 토스 로그인 → `toss-miniapp-toss-login` 스킬 QA 섹션
- 인앱 결제 → `toss-miniapp-iap` 스킬 QA 섹션
- 토스페이 → `toss-miniapp-tosspay` 스킬 QA 섹션
- 인앱 광고 → `toss-miniapp-ads` 스킬 QA 섹션
- 공유 리워드 → 아래 참조
