# 게임 출시 가이드 - 전체 체크리스트

> 공식 문서: https://developers-apps-in-toss.toss.im/checklist/app-game.html

## 공통 기능별 (필수)

### 1. 접속 및 사운드

| # | 항목 | 상세 |
|---|------|------|
| 1 | 최초 로딩 | 미니앱이 **10초 이내**에 최초 화면까지 정상적으로 열림 |
| 2 | 사운드/햅틱 | 배경음, 효과음, 햅틱 기능 적용 |
| 3 | 무음 모드 | 무음 모드에서도 의도한 동작 유지 |
| 4 | 음소거 제어 | 사용자가 음소거 설정 직접 제어 가능 |
| 5 | 백그라운드 전환 | 백그라운드 전환 시 즉시 음성 종료 |
| 6 | 복귀 재생 | 복귀 시 음성 정상 재생 |

### 2. UX 및 내비게이션 바

| # | 항목 | 상세 |
|---|------|------|
| 1 | 닫기 버튼 | 우측 상단 닫기 버튼 정상 노출 및 작동 |
| 2 | Safe Area | Safe Area 침범 금지 (iOS Dynamic Island 포함) |
| 3 | 바텀시트 자동 금지 | 진입 시 바텀시트 자동 출현 금지 |
| 4 | 강제 유도 금지 | 특정 화면 전환 시 사용자 행동 강제 유도 금지 |
| 5 | 종료 가능 | 모든 화면에서 미니앱 퇴출 가능 경로 필수 |
| 6 | CTA 명확성 | CTA 버튼 클릭 결과 예측 가능성 |
| 7 | 자사 앱 유도 금지 | 자사 서비스/앱 설치 유도 링크 금지 |
| 8 | 광고 위치 제한 | 인앱 광고 위치 제한 (인트로/로딩/컷신/팝업 제외) |
| 9 | 브랜드 표시 | 브랜드 로고 및 미니앱 한글명 내비게이션 바 반영 |

### 3. 게임 로그인

| # | 항목 | 상세 |
|---|------|------|
| 1 | 유저 식별 | 유저 식별자 값을 확인하여 저장하고, 게임이 정상적으로 시작됨 |
| 2 | 플레이 기록 | 플레이 기록 유지 (랭킹, 레벨, 스테이지 등) |
| 3 | 재접속 데이터 | 앱 재접속 후 데이터 유지 |

### 4. 서비스 이용 동작

| # | 항목 | 상세 |
|---|------|------|
| 1 | 풀스크린 | 인게임 화면 풀스크린 구현 |
| 2 | 화면 방향 | 설정한 화면 방향(가로/세로) 정상 작동 |
| 3 | iOS 제스처 | iOS 뒤로가기 제스처 비활성화 |
| 4 | 위법 콘텐츠 | 위법 콘텐츠 금지 (불법성, 선정성 등) |
| 5 | UI 정상 작동 | 모든 UI 컴포넌트 정상 작동 |
| 6 | 인터랙션 지연 | 인터랙션 반응 2초 이상 지연 금지 |
| 7 | 권한 동의 | 권한 요청 전 사용자 동의 필수 |
| 8 | 권한 미동의 | 권한 미동의 시에도 기능 정상 작동 |
| 9 | 네트워크 | 비정상적 네트워크 사용량 급증 금지 |
| 10 | 메모리 | 비정상적 메모리 사용량 급증 금지 |
| 11 | 종료 확인 | 앱 종료 시 확인 모달 노출 |
| 12 | 서비스 흐름 | 주요 서비스 흐름 오류 없음 (점수 측정, 스테이지 클리어 등) |

## 선택 기능별

선택 기능의 QA 항목은 각 기능 스킬에서 관리합니다:
- 인앱 결제 → `toss-miniapp-iap` 스킬 QA 섹션
- 인앱 광고 → `toss-miniapp-ads` 스킬 QA 섹션
- 공유 리워드, 웹보드 게임 → 아래 참조

### 공유 리워드

| # | 항목 | 상세 |
|---|------|------|
| 1 | 화면 노출 | 공유 리워드 화면 정상 노출 |
| 2 | 화면 종료 | 화면 종료 후 미니앱 복귀 |
| 3 | 보상 지급 | 친구 초대 완료 시 보상 정상 지급 |

### 웹보드 게임 (해당 시)

| # | 항목 | 상세 |
|---|------|------|
| 1 | 성인 인증 | 성인 인증 기능 연동 |
| 2 | 고객센터 | 고객센터 문의 채널 제공 |
| 3 | 확률 공개 | 확률형 아이템의 확률 정보 사용자 공개 |
