# 앱인토스 미니앱 출시 검수 체크리스트

> 공식 문서:
> - 비게임: https://developers-apps-in-toss.toss.im/checklist/app-nongame.html
> - 게임: https://developers-apps-in-toss.toss.im/checklist/app-game.html

출시 전 반드시 체크리스트를 확인하세요. 유형에 따라 해당 reference 파일을 읽으세요:

- **비게임 미니앱** → `references/checklist-nongame.md`
- **게임 미니앱** → `references/checklist-game.md`

선택 기능별 QA는 각 기능 스킬이 관리합니다:
- 토스 로그인 → `toss-miniapp-toss-login` 스킬
- 인앱 결제 → `toss-miniapp-iap` 스킬
- 토스페이 → `toss-miniapp-tosspay` 스킬
- 인앱 광고 → `toss-miniapp-ads` 스킬

## 검수 실패 주요 원인

1. **내비게이션 바**: 자체 뒤로가기와 토스 내비게이션 중복 노출
2. **인터랙션 지연**: 화면 전환/터치 반응 2초 초과
3. **공유 스킴**: `intoss://` 대신 `https://` 스킴 사용
4. **자사 앱 유도**: 앱 설치 유도 버튼이나 링크 포함
5. **인앱 광고 위치**: 인트로/로딩 화면에 광고 배치
6. **권한 처리**: 권한 거부 시 앱이 동작하지 않음

## 검수 전 최종 확인 순서

```
1. 내비게이션 바 → 뒤로가기/닫기 동작 확인
2. 전체 화면 순회 → UI 깨짐, 지연 없는지 확인
3. 종료/재진입 → 데이터 유지 확인
4. 결제/광고 → 해당 기능 전체 플로우 테스트
5. 권한 → 모든 권한 거부 상태에서 앱 동작 확인
6. 공유 → intoss:// 스킴 확인
```
