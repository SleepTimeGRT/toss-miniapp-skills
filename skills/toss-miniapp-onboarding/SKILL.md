# 토스 미니앱(앱인토스) 온보딩 및 출시 가이드

## 서비스 오픈 프로세스

앱인토스는 **누구나 빠르고 간편하게 미니앱을 출시할 수 있도록 설계된 플랫폼**이에요.

### 1. 시작하기

콘솔에 가입하고 워크스페이스를 설정하는 단계예요. 아래 **콘솔에서 앱 등록하기** 섹션을 참고하세요.

### 2. 디자인하기

앱인토스는 **앱빌더**(웹 기반 UI 디자인 툴)와 **피그마(Figma)** 두 가지 디자인 툴을 제공해요. TDS 라이브러리와 주요 컴포넌트가 포함되어 있어 빠르게 완성할 수 있어요.

### 3. 개발하기

앱인토스는 SDK와 API를 제공해 빠르게 개발할 수 있어요. API 사용을 위해서는 필수로 mTLS(mutual TLS) 인증서를 설정해야 해요.

### 4. 검수하기

**4단계 검수 절차**를 거쳐요. 평균 소요 시간은 **2~3일**이에요.

1. **운영 검수** : 앱 정보, 노출 정보, 서류 확인
2. **기능 검수** : 앱이 토스앱 안에서 오류 없이 정상 작동하는지 확인
3. **디자인 검수** : 토스 UI 가이드 준수 여부 검토
4. **보안 검수** : 개인정보/보안 관련 문제 없는지 확인

> **게임 미니앱은 반드시 심의를 완료해야 런칭할 수 있어요.**
> 1. [게임물관리위원회](https://www.grac.or.kr/)를 통한 심의 후 등급분류증명서 첨부
> 2. 자체등급분류사업자를 통한 앱 출시 시 등급 심의 후 스토어에 출시된 링크 첨부

### 5. 미니앱 출시

검수가 완료되면 결과가 이메일로 안내돼요. 승인 후에는 콘솔에서 '출시하기' 버튼을 눌러 바로 오픈할 수 있어요.

## 콘솔에서 앱 등록하기

> **사업자가 없는 경우:** 개인 개발자는 사업자 등록 없이도 앱을 만들 수 있어요. 단, 수익화 기능 및 토스 로그인은 사용할 수 없어요. 사업자 등록은 [국세청 홈택스](https://hometax.go.kr/)에서 신청 가능 (보통 3일 내 발급).

### 1. 회원가입하기

[앱인토스 콘솔](https://apps-in-toss.toss.im/)에서 회원가입. **만 19세 이상**, **본인 명의 토스앱** 필요.

### 2. 워크스페이스 설정하기

사업자당 1개의 워크스페이스. 이름은 중복 불가, 나중에 수정 가능.

### 3. 멤버 초대하기

워크스페이스 생성자에게 **대표관리자** 권한이 자동 부여돼요. '멤버' 메뉴에서 **'+초대하기'**로 팀원 초대.

* **관리자**: 멤버 관리, 설정 변경 등 모든 권한
* **구성원**: 공동 작업 가능, 멤버 초대/설정 변경 제한

대표관리자 변경: 현재 대표관리자가 [권한 위임] 버튼 클릭. 사업자 정보 등록 여부와 약관 동의 이력에 따라 추가 절차가 달라질 수 있어요.

### 4. 앱 등록하기

'앱' 메뉴에서 **'+등록하기'**로 앱 등록. 개발 완료 전이라도 미리 등록 가능.

#### 4-1) 기본 정보

* **앱 로고**: 정사각형 600x600px, PNG(배경색 필수, 투명 배경 불가). [앱 로고 가이드.zip](/resources/prepare/logo_guide.zip) 참고.
* **앱 이름**: 서비스 성격이 바로 이해되도록 작성. 영문명은 15자 이내 명사형.
* **appName**: 앱 스킴 호출 시 사용되는 ID (`intoss://` 형식). 한 번 등록 후 수정 불가.
* **사용 연령**: 현재 만 19세 이상만 제공.
* **고객센터 정보**: 이메일/연락처/채팅 상담 주소 입력.

#### 4-2) 카테고리 및 노출

##### 이미지/스크린샷 규격

| 항목 | 규격 | 형식 |
|------|------|------|
| 정방형 썸네일 | 1000 x 1000px | PNG |
| 가로형 썸네일 | 1932 x 828px | PNG |
| 세로형 스크린샷 | 636 x 1048px (최소 3장) | PNG |
| 가로형 스크린샷 | 1504 x 741px (최소 1장) | PNG |

* **부제**: 서비스를 쉽고 간결하게 설명. 비속어/느낌표 사용 불가.
* **상세 설명**: 선택사항. 토스 홈 광고 대상 선정에 활용될 수 있어요.
* **앱 검색 키워드**: 토스 앱 전체 메뉴 검색에 활용. 미니앱과 관련 없는 키워드 불가.
* **[비게임 앱] 카테고리**: 대분류/중분류/소분류 설정. 실제 서비스와 다르면 검토 과정에서 수정 안내.
* **[게임 앱] 리더보드**: 점수 단위와 정렬 기준 등 정책 설정.

#### 4-3) 게임 등급분류

> 게임 등급분류 상세 절차(스토어 심사/게임물관리위원회 심의/자체등급분류 정보 입력)는 [references/game-rating.md](references/game-rating.md) 참고.

## 사업자 등록하기

수익화 기능(인앱 광고, 인앱 결제, 토스페이, 프로모션, 비즈월렛, 토스 로그인)을 사용하려면 사업자 등록이 필요해요.

> 법인/개인 사업자별 필요 서류 및 상세 절차는 [references/business-registration.md](references/business-registration.md) 참고.

## 서비스 오픈 정책

출시 전 반드시 확인해야 하는 필수 정책이에요. 위반 시 반려 또는 운영 제한이 적용될 수 있어요.

**제한되는 서비스 요약:** 가상자산/NFT, 자금세탁, 불법/부정행위, 사행성/베팅, 금융상품 중개, 투자 자문/리딩방, 기타 내부 정책 위반.

**주요 정책:** 자격 필요 카테고리(의료/쇼핑몰/교육), 어뷰징 방지(유사 앱 반복 출시 금지), 자사 앱 설치 유도/외부 링크 제한, 생성형 AI 서비스 고지/표시 의무.

> 전체 서비스 오픈 정책 상세 내용은 [references/service-policy.md](references/service-policy.md) 참고.
